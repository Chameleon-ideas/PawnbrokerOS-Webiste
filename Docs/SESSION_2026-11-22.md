**Why `~7.3.8` and not the latest 7.4.x:** Astro 7.4.x declares `node >=22.23.4` and **refuses to
build** on older Node (`Node.js v22.14.0 is not supported by Astro!`). Local Node is 22.14 and the
deploy host's Node version is unknown (host still unidentified). 7.3.8 needs only `node >=22.12.0`.
The tilde keeps it from drifting to 7.4 on a future `npm install`.

**Remaining audit finding (1 moderate, `astro <=7.4.6`)** — not reachable on this site:
- XSS via dynamic tag names — no component renders a dynamic tag (`grep` finds none).
- Image-endpoint file read in `@astrojs/node` — the site is static, no adapter.

Moving to 7.4.x clears it, but requires Node ≥ 22.23.4 both locally and on the host.
