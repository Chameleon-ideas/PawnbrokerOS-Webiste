## 7. Calendly opens on the page, not in a new tab

`DemoCard.astro` script: "Book a Free Demo" (`a[data-calendly]`) loads Calendly's official
widget (assets.calendly.com widget.js/css) on first click and calls `initPopupWidget`, with
`hide_gdpr_banner=1` so Calendly's cookie notice doesn't cover the calendar. If the navbar
booking popup is open it is closed first (a modal <dialog> sits above Calendly's overlay).
If the widget can't load within 6s (offline / blocked), the link opens Calendly in a new tab
as before; Cmd/Ctrl-click still opens a tab. Tested from the hero card and the navbar popup.

Note for the owner: the Calendly event's organisation name reads "PawnbrockerOS" (typo) —
that is set in the Calendly account, not the website.
